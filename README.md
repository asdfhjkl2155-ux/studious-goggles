# بوت توليد الفيديو

ترسل وصفاً نصياً للبوت في تيليجرام، فيرجع لك فيديو مولّداً بالذكاء الاصطناعي.

- بدون حدود استخدام داخل البوت: لا عدد يومي ولا قائمة انتظار خاصة به.
- بوت خاص: لا يستجيب إلا للأرقام المسجلة في `ALLOWED_USER_IDS`، لأن كل فيديو يُخصم من رصيدك.
- التوليد عبر [fal.ai](https://fal.ai)، بمفتاح واحد لعدة موديلات (Veo و Kling و Wan).

## التشغيل

1. أنشئ بوتاً من [@BotFather](https://t.me/BotFather) بالأمر `/newbot` وانسخ الـ token.
2. أنشئ مفتاحاً من <https://fal.ai/dashboard/keys> واشحن رصيداً.
3. جهّز المشروع:

   ```bash
   python3 -m venv venv && source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   python set_keys.py        # يطلب token البوت ومفتاح fal بدون عرضهما
   python bot.py
   ```

4. في أول تشغيل يطبع البوت "رمز الربط" في Terminal. أرسله للبوت في تيليجرام، فيُحفظ حسابك تلقائياً كمالك في `ALLOWED_USER_IDS`.
5. اكتب وصف الفيديو في رسالة.

## الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `/duration` | مدة الفيديو من 3 إلى 20 ثانية (أزرار، أو `/duration 12`) |
| `/quality` | الجودة: 720p أو 1080p |
| `/aspect` | أفقي 16:9 أو عمودي 9:16 |
| `/model` | الموديل. الافتراضي "تلقائي": يختار الأنسب للمدة والجودة |
| `/settings` | عرض الإعدادات الحالية وما سينتج عنها |
| `/id` | عرض رقم حسابك |

تضبط المدة والجودة مرة واحدة، وبعدها ترسل الوصف فقط.

### المدة والجودة المتاحة

| الموديل | المدة (ثانية) | الجودة |
| --- | --- | --- |
| Veo 3.1 Lite (مع صوت) | 4، 6، 8 | 720p، 1080p |
| Wan 2.6 | 5، 10، 15 | 720p، 1080p |
| Kling 4.0 Flash | من 3 إلى 20 | 720p فقط |
| LTX 2.3 Fast (الأرخص، مع صوت) | 6، 8، 10 | 1080p فقط |

- الوضع التلقائي يختار الأقرب للمدة المطلوبة ثم **الأرخص**. مثال: 8 ثوانٍ بجودة 720p تذهب إلى LTX بجودة 1080p بحوالي 0.32 دولار بدل 0.40 على Veo. `/settings` يعرض التكلفة التقريبية قبل التوليد.
- إذا طلبت تركيبة غير متاحة، يحافظ البوت على الجودة ويقرّب المدة، ويخبرك بالتعديل. مثال: 20 ثانية بجودة 1080p تصبح 15 ثانية.
- أقصى مدة للمقطع الواحد 20 ثانية. الفيديو الأطول يحتاج دمج عدة مقاطع، وهذا غير مضاف بعد.

## التشغيل المحلي على الماك (مجاني)

الموديل LTX-2 يعمل على جهازك مباشرة، بدون رصيد وبدون حد استخدام. يحتاج ماك بشريحة Apple (M1 أو أحدث)، ذاكرة 16GB كحد أدنى (32GB أفضل)، و 60GB مساحة فارغة تقريباً.

```bash
bash setup_mac.sh
```

السكربت يفحص الجهاز، يثبّت المكتبات، ينزّل الموديل، ويولّد مقطع تجربة `test_video.mp4`. بعدها في البوت: `/model` ثم اختر "LTX-2 محلي".

| | محلي (LTX-2) | fal |
| --- | --- | --- |
| التكلفة | مجاني | بالثانية |
| المدة | من 3 إلى 10 ثوانٍ | حتى 20 ثانية |
| الدقة | 768×448 (خيار 720p) أو 1280×704 (خيار 1080p) | 720p و 1080p حقيقية |
| السرعة | دقائق أو أكثر حسب الجهاز | من 1 إلى 5 دقائق |

- الصوت معطّل افتراضياً في المحلي. للتجربة ضع `LOCAL_AUDIO=1` في `.env`.
- التوليد المحلي واحد في كل مرة؛ الطلب الثاني ينتظر دوره.
- البوت يعمل بالموديل المحلي فقط إذا تركت `FAL_KEY` فارغاً.

## بدون تيليجرام

```bash
python videogen.py "a red fox running through snow at sunrise, cinematic" --duration 10 --quality 1080p --aspect 9:16 --out fox.mp4
```

## ملاحظات

- **التكلفة:** الدفع لـ fal بالثانية، فالمدة الأطول والجودة الأعلى أغلى. راجع السعر في صفحة الموديل قبل الاستخدام الكثيف.
- **المحتوى:** فلاتر المحتوى تابعة لمزوّد الموديل وليست في هذا الكود. إذا رُفض وصف، يعرض البوت رسالة الرفض كما هي.
- **الموديلات:** المعرّفات وقيم المدة والجودة في `videogen.py` (القاموس `MODELS`). إذا رفض موديل قيمة المدة أو الجودة، يعيد البوت التوليد بإعدادات الموديل الافتراضية ويخبرك.
- **التشغيل الدائم:** البوت يعمل ما دام `python bot.py` شغّالاً. للتشغيل 24/7 ضعه على سيرفر صغير (VPS) أو خدمة مثل Railway.
